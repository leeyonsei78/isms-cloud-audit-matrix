# 클라우드 ISMS 점검 매트릭스

AWS·Azure 인프라에 대한 ISMS(-P) 인증심사를 준비할 때 점검해야 할 인증기준 항목을 정리한 참고 자료입니다.

- ISMS-P(2022 개정 인증기준) 영역 2 "보호대책 요구사항" 중 클라우드 인프라 기술점검과 직결되는 **7개 영역(2.5, 2.6, 2.7, 2.9, 2.10, 2.11, 2.12) · 17개 통제항목**을 다룹니다.
- 항목별로 **AWS와 Azure를 나란히 비교**해 (1) 점검 CLI 명령어, (2) 문제로 판단하는 기준, (3) 개선 방안을 정리했습니다.

## 사용 방법

`isms-cloud-audit-matrix.html` 파일을 브라우저로 열면 됩니다.

- 모든 텍스트(설명·명령어·판단기준·개선방안)를 직접 편집할 수 있고, 편집 내용은 브라우저 로컬 저장소에 자동 저장됩니다.
- 검색창과 영역별 필터 칩으로 원하는 항목만 볼 수 있습니다.
- 명령어 블록에는 복사 버튼이 있습니다.
- "CSV로 내보내기(Excel용)" 버튼은 Claude 아티팩트 환경(claude.ai)에서 열었을 때만 동작하며, 로컬 브라우저에서 파일을 직접 열었을 때는 다운로드 기능이 비활성화됩니다.

## 참고 사항

이 자료는 실무 참고용으로 재구성한 것으로, KISA(한국인터넷진흥원)의 공식 심사 자료를 대체하지 않습니다. 명령어는 조직의 계정 구조·리전·CLI 버전·권한에 맞게 조정해서 사용하세요.
